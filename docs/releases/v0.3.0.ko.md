# SF-Twin ARM Cell v0.3.0 릴리즈 후보 노트

> 현재 공식 배포 버전은 v0.2.0입니다. 이 문서는 Public Draft PR 검토 중인 v0.3.0 후보이며 별도 릴리즈 발행 절차가 끝나기 전까지 정식 릴리즈가 아닙니다.

## v0.2.0 이후 주요 변경

- **Geometry-first Vision:** RGB-D 관측과 알려진 작업물 기하를 활용하고, 부분 관측에서 형상 가설을 복원합니다. 모든 장면에서 검출 성공을 보장하거나 학습 기반 방법보다 우월하다는 뜻은 아닙니다.
- **Vision/Motion 책임 분리:** Vision은 관측 Geometry를 전달하고 Motion은 요청별 planning occupancy를 구성하며 현재 선택한 후보를 제외합니다.
- **재사용 Motion 실행 구조:** Behavior Tree 기반 재사용 Action 경계와 task 전략 구성을 정리했습니다. PICK 후보 순서와 occupancy 제외 휴리스틱을 포함하지만 일반 장면의 성능 개선률을 주장하지 않습니다.
- **Orchestration·Safety·Recovery:** 상태 소유권, 실패 복구 흐름, Safety reset 이후 재개 경계를 개선했습니다.
- **진단 및 증거:** Acquisition Snapshot과 Vision/Motion 계획 근거를 연결하고 컴포넌트별 기록을 확장했습니다. 공개 패키지에는 원본 로컬 진단 로그 전체를 포함하지 않습니다.
- **Sim-to-Real 방향:** simulator 전용 realization을 상위 ROS 계약과 분리하는 설계 근거를 기록했습니다. 실물 하드웨어 어댑터나 실물 운전 검증을 의미하지 않습니다.
- **기술 기록:** 2026-10-30에 통합된 9개 Engineering Story를 공개 문서 구조로 반영했습니다. Private 링크와 로컬 artifact 경로는 공개 문서에서 제거하거나 일반 참조로 바꾸었습니다.

## 검증 범위와 알려진 제한

- 공개 저장소 Docker 이미지 빌드와 `arm_cell_bringup`까지 ARM Cell 패키지 12개 컴파일이 성공했습니다. PR #12에서 TRAC-IK 2.0.1을 `/opt/trac_ik`에 설치하고 MoveIt pluginlib 로딩, ARM Cell IK 플러그인 초기화 및 `solve_type=Distance`를 확인했습니다. 이는 실제 IK 목표 자세 계산을 확인한 것이 아닙니다. 전체 공개 checkout을 제공한 `colcon test --packages-up-to arm_cell_bringup` 및 `colcon test-result --all --verbose`는 1,887개 결과 집계에서 error 2건, failure 133건, skipped 229건으로 실패했습니다. CTest 상위 결과와 leaf XML이 함께 집계되므로 이 수치는 고유 assertion 수가 아닙니다. Formatting/style failure는 uncrustify 89건입니다. 나머지 실패에는 synthetic full-cell nominal mission 결과 불일치, Motion/VDA/Gateway launch 및 timing 경계, MoveIt 설정·scene loader 검사, Vision Snapshot 저장/metadata 검사가 포함됩니다. 두 error 보고는 실패/timeout한 GTest가 결과 XML을 만들지 못한 항목입니다. 전체 checkout 결과에서 필수 자산 누락은 재현되지 않았습니다. 기존 실패는 릴리즈 발행 전 조사 대상입니다. Docker 빌드와 플러그인 초기화 성공은 Isaac Sim 라이브 실행 검증이 아닙니다. 기본 MoveIt kinematics 파일은 일반 MoveIt group에 KDL을 선택하지만, 기본 operational profile은 PICK에 TRAC-IK를 선택하고 Motion이 해당 플러그인을 별도로 초기화합니다. Docker 검증은 전체 Motion Launch를 포함하지 않았습니다.
- 별도 Private 환경의 2026-10-30 최신 clean 라이브 기록은 E-Stop 이후 reset, SafetyRecovery, GO_HOME 성공 및 Mission의 PnP 재개를 확인합니다. 이후 approach는 `BACKEND_UNAVAILABLE`로 종료되어 전체 Mission은 성공하지 않았습니다. 이 근거는 해당 revision·환경의 범위이며 Public Docker 검증과 별개이고 일반 복구율을 입증하지 않습니다.
- RGB-D Acquisition에는 depth 수신 공백과 synchronization callback 미발생이 기록돼 있습니다. 공통 원인 또는 완전한 해결은 확인되지 않았습니다.
- PLACE `WAYPOINT` 전략은 실험적이며 미완성입니다. 완료된 경로 최적화나 기본 운영 전략으로 소개하지 않습니다.
- 비교 가능한 benchmark가 없어 정량 성능 향상은 주장하지 않습니다.
- Software Safety는 안전 등급 E-stop/STO 하드웨어를 대체하지 않습니다. AMR 내비게이션, 실물 로봇 acceptance와 전체 VDA 5050은 범위 밖입니다.

## 발행 전 확인

Public PR 검토에서 공개 문서·링크·라이선스와 Docker/ROS 검증 결과를 확인하고 남은 테스트 실패와 검증 범위를 고려한 뒤, PR 병합 후 최종 Public `main`을 기준으로 별도 절차에서 `v0.3.0` 태그와 GitHub Release를 발행해야 합니다. 이번 후보 작업에는 병합이나 태그 발행이 포함되지 않습니다.
