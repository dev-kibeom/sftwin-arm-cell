# SF-Twin ARM Cell v0.3.0 릴리즈 후보 노트

> Draft 릴리즈 후보 문서입니다. Public Draft PR 검토와 별도 릴리즈 발행 절차가 끝나기 전까지 정식 릴리즈가 아닙니다.

## v0.2.0 이후 주요 변경

- **Geometry-first Vision:** RGB-D 관측과 알려진 작업물 기하를 활용하고, 부분 관측에서 형상 가설을 복원합니다. 모든 장면에서 검출 성공을 보장하거나 학습 기반 방법보다 우월하다는 뜻은 아닙니다.
- **Vision/Motion 책임 분리:** Vision은 관측 Geometry를 전달하고 Motion은 요청별 planning occupancy를 구성하며 현재 선택한 후보를 제외합니다.
- **재사용 Motion 실행 구조:** Behavior Tree 기반 재사용 Action 경계와 task 전략 구성을 정리했습니다. PICK 후보 순서와 occupancy 제외 휴리스틱을 포함하지만 일반 장면의 성능 개선률을 주장하지 않습니다.
- **Orchestration·Safety·Recovery:** 상태 소유권, 실패 복구 흐름, Safety reset 이후 재개 경계를 개선했습니다.
- **진단 및 증거:** Acquisition Snapshot과 Vision/Motion 계획 근거를 연결하고 컴포넌트별 기록을 확장했습니다. 공개 패키지에는 원본 로컬 진단 로그 전체를 포함하지 않습니다.
- **Sim-to-Real 방향:** simulator 전용 realization을 상위 ROS 계약과 분리하는 설계 근거를 기록했습니다. 실물 하드웨어 어댑터나 실물 운전 검증을 의미하지 않습니다.
- **기술 기록:** 2026-10-30 Private PR #747에서 통합된 9개 Engineering Story를 공개 문서 구조로 반영했습니다. Private 링크와 로컬 artifact 경로는 공개 문서에서 제거하거나 일반 참조로 바꾸었습니다.

## 검증 범위와 알려진 제한

- 공개 저장소 Docker Build에서 `arm_cell_bringup`까지 12개 패키지를 컴파일했습니다. 전체 checkout을 제공한 `colcon test --packages-up-to arm_cell_bringup`은 1,890개 test 집계에서 error 1건, failure 113건, skipped 229건으로 실패했습니다. 실패에는 uncrustify 89건, synthetic nominal mission 결과 불일치, MoveIt launch 설정, Vision Snapshot 검증이 포함됩니다. 이 결과는 릴리즈 발행 전 후속 수정이 필요한 상태입니다. 빌드 성공은 Isaac Sim 라이브 실행 검증이 아닙니다. 기본 MoveIt kinematics 파일은 KDL을 선택하지만 기본 operational profile은 PICK에 TRAC-IK를 선택합니다. Docker compile image에는 해당 실행 플러그인이 없어 기본 operational PICK 흐름을 실행할 수 없습니다. 호환 플러그인 설치와 runtime launch는 검증하지 않았습니다.
- 2026-10-30 최신 clean 라이브 기록은 E-Stop 이후 reset, SafetyRecovery, GO_HOME 성공 및 Mission의 PnP 재개를 확인합니다. 이후 approach는 `BACKEND_UNAVAILABLE`로 종료되어 전체 Mission은 성공하지 않았습니다. 이 근거는 해당 revision·환경의 범위이며 일반 복구율을 입증하지 않습니다.
- RGB-D Acquisition에는 depth 수신 공백과 synchronization callback 미발생이 기록돼 있습니다. 공통 원인 또는 완전한 해결은 확인되지 않았습니다.
- PLACE `WAYPOINT` 전략은 실험적이며 미완성입니다. 완료된 경로 최적화나 기본 운영 전략으로 소개하지 않습니다.
- 비교 가능한 benchmark가 없어 정량 성능 향상은 주장하지 않습니다.
- Software Safety는 안전 등급 E-stop/STO 하드웨어를 대체하지 않습니다. AMR 내비게이션, 실물 로봇 acceptance와 전체 VDA 5050은 범위 밖입니다.

## 발행 전 확인

Draft PR 검토에서 공개 문서·링크·라이선스와 Docker/ROS 검증 결과를 확인하고 잔여 문제를 정리한 뒤 별도 절차로 `v0.3.0` 태그와 GitHub Release를 발행해야 합니다. 이번 후보 작업에는 병합이나 태그 발행이 포함되지 않습니다.
