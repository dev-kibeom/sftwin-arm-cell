# SF-Twin ARM Cell v0.3.3 릴리즈 노트

> v0.3.3은 recipe 기반 PICK 파지 깊이, 자재 치수 기반 중심 계산, Isaac attach 시점 개선을 포함하는 엔지니어링 및 시뮬레이션 릴리즈입니다.

## v0.3.2 이후 주요 변경

- **Recipe별 파지 깊이:** `pick.grasp_backoff_m`을 추가했습니다. RawPart recipe는 0.02m, cube profile은 0m를 사용합니다. 보정은 후보의 최종 TCP 접근 축 반대 방향으로 적용됩니다.
- **자재 치수 기반 중심:** 고정 `observation_to_object_translation`을 제거했습니다. 관측 상판에서 선택한 면의 알려진 자체 두께 절반만큼 안쪽으로 이동해 자재 중심을 계산합니다. 두께가 없는 PICK 입력은 잘못된 목표로 거절합니다.
- **Fixed Vision 치수 전달:** validation fixture 등록에 알려진 자재 치수를 포함하고, Vision 후보가 이를 상판 치수와 자체 두께로 전달합니다.
- **대상별 attach 판정:** 선택된 Vision 대상 자재를 연결하고 TCP가 보정된 파지 목표에 도달했는지 판정합니다.
- **Close 후 attach 시점:** 자재가 capture 영역에 들어온 즉시 close를 멈추지 않습니다. 측정 그리퍼 폭이 예상 접촉 폭과 허용 오차 안에 들어오면 attach합니다. 물리 접촉 감지는 요구하지 않습니다.
- **Ubuntu 미러:** Docker 빌드가 Ubuntu 기본 미러에 연결하지 못하는 환경을 위해 Kakao HTTPS 미러를 사용합니다.

## 업그레이드

- ROS Action 및 Fixed Vision 등록 서비스 인터페이스가 변경됐습니다. 전체 Bringup 이미지와 Isaac 런타임을 함께 갱신하세요.
- Docker Compose 사용자는 저장소 루트에서 `docker compose up --build`로 이미지를 다시 빌드합니다.
- 자체 Recipe에는 유한한 비음수 `pick.grasp_backoff_m` 필드를 지정하세요. 단위는 metre입니다.

## 검증 범위와 알려진 제한

- `arm_cell_bringup`까지 ROS 패키지 10개 빌드가 통과했습니다.
- 관련 CTest 10개 모음과 Python 테스트 398개가 통과했습니다.
- 라이브 Isaac 테스트에서 파지 성공을 확인했습니다.
- 실물 로봇 운전과 안전 등급 E-stop/STO 하드웨어 검증은 포함하지 않습니다.
