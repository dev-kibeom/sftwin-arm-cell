# SF-Twin ARM Cell v0.3.3 Release Notes

> v0.3.3 is an engineering and simulation release with recipe-driven PICK grasp depth, material-dimension-based object centers, and improved Isaac attachment timing.

## Changes since v0.3.2

- **Per-recipe grasp depth:** Added `pick.grasp_backoff_m`. The RawPart recipe uses 0.02 m and the cube profile uses 0 m. The offset is applied opposite the final candidate TCP insertion axis.
- **Material-dimension-based center:** Removed the fixed `observation_to_object_translation`. The object center is computed inward from the observed top surface by half the selected face's known thickness. PICK inputs without thickness are rejected as invalid goals.
- **Fixed Vision dimensions:** Validation fixture registration carries known material dimensions, which Fixed Vision returns as top-face dimensions and own thickness.
- **Target-specific attachment:** The selected Vision material is associated with the grasp, and capture checks whether the TCP reaches the corrected grasp target.
- **Attachment after closing:** Entering the capture volume no longer stops closing immediately. Attachment occurs when measured gripper width reaches the expected contact width within tolerance. Physical contact sensing is not required.
- **Ubuntu mirror:** Docker builds use the Kakao HTTPS mirror for Ubuntu packages in environments that cannot reach the default Ubuntu mirror.

## Upgrading

- ROS Action and Fixed Vision registration service interfaces changed. Update the complete Bringup image and Isaac runtime together.
- Docker Compose users should rebuild from the repository root with `docker compose up --build`.
- Custom recipes must specify a finite, nonnegative `pick.grasp_backoff_m` value in metres.

## Verification and known limitations

- All 10 ROS packages built through `arm_cell_bringup`.
- Ten affected CTest suites and 398 Python tests passed.
- A live Isaac test confirmed successful grasping.
- Physical-robot operation and safety-rated E-stop/STO hardware verification are outside this release's scope.
