# ARM Cell — Definition

- **문서 유형:** Product Definition
- **대상:** ARM Cell / Isaac Sim 기반 통합 데모
- **Owner:** ARM Cell Product

## 1. 제품 비전과 목적

ARM Cell은 외부 자재 공급, RGB-D 인지, 개별 로봇 작업 실행, 운영자 관측과 이상 상황 대응을 하나의 로봇 셀에서 통합해 검증하는 시스템이다. **장기 목표는 시뮬레이션 구동 자체가 아니라 실제 로봇 셀에도 적용 가능한 Sim-to-Real 시스템의 구축**이다.

현재 제품 검증 범위는 **Isaac Sim 기반 통합 데모**다. 현실의 로봇·센서·자재 및 물리적 상호작용을 가능한 범위에서 모사하며, 시뮬레이션과 실제 환경의 불가피한 차이는 향후 실제 장비의 Calibration과 별도 검증으로 다룬다. 데모 완료는 실제 공장 배치, 하드웨어 안전 인증 또는 생산 설비 검증의 완료를 의미하지 않는다. 데모 수준의 제품 의미는 특정 ROS 구현, UI 구성, 시뮬레이터 객체 ID, 물리 배치에 종속되지 않는다.

## 2. 대상 사용자와 가치

| 대상 | 제품 수준 목표 |
|---|---|
| 운영자 | 작업 진행·대상 인지·상태·이상 및 복구 가능 여부를 관측하고 허용된 요청을 수행 |
| 통합·검증 담당자 | 자재 공급부터 처리 결과까지 통합 실행을 확인하고 독립 시나리오별 근거를 확보 |
| 외부 자재 공급 주체 | 이미 배정한 공급 사실을 정해진 경계를 통해 전달 |

## 3. 제품 범위 및 비목표

- **포함:** 승인된 외부 자재 인계, 공급 수량 기반 연속 PnP, 최신 RGB-D 기반 대상 검출, 운영자 관측, 대표 이상·정지·복구 흐름, 반복 실험 및 최종 라이브 인수.
- **범위:** Isaac Sim 및 교체 가능한 외부 시스템 Mock·공급 Adapter에 의한 실제 실행 결과의 통합 데모.
- **비목표:** 실제 AMR 하드웨어·주행, 실제 공장 네트워크, 별도 Qt HMI, CNC 애니메이션, 하드웨어 FAT/SAT, 상용 수준 UI 스타일, 특정 Vision 알고리즘·ROS 구현·지연 임계치·Isaac Prim 경로·양산용 그리퍼 구현.
- **후속 범위:** 실제 로봇 셀 적용과 현장 Calibration·검증은 장기 목표를 실현할 후속 단계로, 현재 데모의 인수 조건은 아니다. Release 뒤 정착 Pose 품질 검사와 Process Verification도 이번 PLACE 성공 조건이 아니다. 장래 실제 장비 통합은 현재 Mission·Target·Holding·Release·Safety·Fault·Recovery 의미를 변경하지 않고 확장 가능해야 한다.

## 4. 핵심 Capability

| 능력 | 제품 의미 | 정식 상세 |
|---|---|---|
| 자재 인계와 배치 처리 | 공급 근거를 받아 관측된 자재를 수량 기반 작업으로 처리 | 자재 공급·배치 처리 |
| 운영자 관측 | 데모 UI에서 인지·결과·요청을 구분하여 제공 | 운영자 관측 |
| 이상 대응·복구 | 안전 감독, 허용된 복구, 정지와 불확실성 처리 | 이상 대응·복구 |
| 실험 세션 | 반복 실험의 상태 분리·재시작과 진단 근거 | 시뮬레이션 세션 |

## 5. 제품 수준 품질·제약

- 운영자 UI, Gateway, Vision, Task Execution, Motion, Safety 등은 정식 결과 Owner의 판단을 덮어쓰지 않는다.
- 공급 완료와 Material Readiness는 자재의 가시성·파지 가능성·성공적 PnP를 보장하지 않는다.
- 시뮬레이터 객체 정답을 생산 Vision의 검출 근거로 사용하지 않는다.
- Safety의 물리 E-Stop/STO 대체 또는 안전 등급 인증을 주장하지 않는다.
- 각 Capability의 세부 보장과 비보장, 실행·계약 의미는 해당 Product 및 승인된 CDS/FDS/ICD Owner에 남긴다.

## 6. 제품 성공·데모 완료 기준

**Demo Complete**는 현재 적용되는 live-current 기준선에 대해 **필수 독립 시나리오 전체가 하나 이상의 대표 Isaac Sim 라이브 세션에서 PASS**하고 적절한 지속 근거가 확보된 상태다. 단일 장시간 시연이 독립 시나리오 집합을 대신하지 않는다.

이 판단은 수량 기반 Mission, 관측 가능성, 심각도에 따른 이상 대응, 통제 정지·긴급 중단, Holding·Target 유효성 보호, 허가된 복구와 그 근거의 전체 결과를 통합 평가한다. 상세 전제·자극·기대 전이·관측 근거·PASS·비보장은 [최종 라이브 인수 계약](acceptance.md)이 정식으로 소유한다. 검증 보고서는 특정 기준선에서의 달성 증거를 소유하며 이 요구를 재정의하지 않는다.

## 7. 대표 Use Case

- 공급된 자재의 배치 처리
- 작업 상태와 인지 결과 관측
- 이상 상황에서 정지·복구
- 새 시뮬레이션 실험 수행
